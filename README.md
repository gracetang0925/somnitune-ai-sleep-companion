# SomniTune 星梦

**个性化 AI 睡眠陪伴与音乐偏好追踪原型**  
Independent product strategy, content operations and data operations case by **Grace Tang 汤夏禛**.

SomniTune explores one product question: when sleep-content libraries keep growing, how might a product remember what actually works for each user's bedtime routine?

## Case scope

- Three content jobs: guided meditation, sleep music and gentle bedtime rituals
- Clickable recommendation → session → feedback flow
- Four-event measurement model: `content_impression → content_select → session_complete → feedback_submit`
- Lightweight preference profile combining metadata, behaviour and explicit feedback
- Explainable recommendations and a four-week validation plan
- Responsive static site built with HTML, CSS and JavaScript

## Truth and safety note

This is an independently created concept prototype. Personas, content and event values are simulated for design demonstration; they are not live product results or clinical evidence. SomniTune is positioned as a bedtime relaxation and content-preference tool, not a medical diagnostic or treatment product.
